# Setup Instructions

## Requirements
*   Android Studio
*   A physical Android device (API 29+ recommended). *Note: `LocalOnlyHotspot` requires physical Wi-Fi hardware and will not work on standard emulators.*

## Building the App
1.  Open the `broadcast-app` folder in Android Studio.
2.  Sync the Gradle project.
3.  Connect your physical Android device via USB.
4.  Click **Run** (Play button) to install the app.

## Permissions
On the first launch, the app will request Location / Nearby Devices permissions. These are strictly required by Android OS to create and manage local Wi-Fi hotspots. Accept the permissions to proceed.
